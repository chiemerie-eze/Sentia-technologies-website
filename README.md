## Overview

The Sentia Technologies Website is the official digital presence of Sentia Technologies Limited, a cybersecurity and technology consulting company focused on helping startups, SMEs, and growing organisations strengthen their security, modernise their infrastructure, and adopt secure digital technologies.

The website presents Sentia's services, technical capabilities, company vision, industry insights, and the Sentia Security Platform while providing prospective clients with a clear way to engage with the business.

---

## Why This Project Exists

This project was created to establish a professional digital presence for Sentia Technologies and communicate the company's mission, technical expertise, and service offering.

The website provides a central platform where organisations can learn about Sentia's cybersecurity, cloud, digital transformation, and web development capabilities, explore insights, and request consultations.

It also demonstrates practical experience in modern frontend development, responsive design, deployment, DNS configuration, and maintaining a production business website.

## Architecture

The website uses a component-based frontend architecture designed to keep the codebase organised, reusable, and maintainable.

The application is structured around reusable React components for navigation, content sections, service cards, calls to action, and other interface elements.

The frontend is separated into logical sections and assets, allowing new pages, services, and content to be added without rebuilding the entire application.

The production architecture includes:

- React-based frontend
- Reusable UI components
- Responsive layouts
- Static assets and media
- Git and GitHub for version control
- Netlify for production deployment
- Cloudflare for DNS management and domain configuration
