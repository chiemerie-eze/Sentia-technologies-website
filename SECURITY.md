# Security Policy

## Our Commitment

At Sentia Technologies Limited, security is at the core of everything we build. We appreciate the efforts of security researchers and the wider community in helping us identify and address potential security issues responsibly.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly by contacting us directly.

**Email:** security@sentiatechnologieslimited.com

Please include:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- Any proof-of-concept (if available)
- The potential impact
- Suggested remediation (if known)

Please do not disclose the vulnerability publicly until it has been investigated and resolved.

## Response Process

Once a report has been received, we aim to:

- Acknowledge receipt within 3 business days.
- Investigate and validate the reported issue.
- Develop and test an appropriate fix.
- Keep the reporter informed throughout the process where appropriate.

The time required to resolve an issue depends on its complexity and potential impact.

## Responsible Disclosure

We kindly ask that security researchers:

- Act in good faith.
- Avoid accessing or modifying data that does not belong to them.
- Do not interrupt or degrade our services.
- Allow us reasonable time to investigate and resolve reported vulnerabilities before any public disclosure.

## Supported Versions

Security updates are provided for the latest stable version of this project.
